# Jongrai January Homepage Mockup

An isolated, static homepage concept for visual testing.

- Preview route: `/mockup/` (when served by the Jongrai web server)
- Uses fictional/sample match, hero and leaderboard data only.
- No API calls, backend integration, or production JavaScript/CSS dependencies.
- Main hero artwork: `/icons/season 42.jpg`
- The leaderboard tabs and mobile navigation are interactive.

This folder is a design prototype. It does not replace the production homepage.
