About Project Jongrai

An independent draft analysis tool for Mobile Legends: Bang Bang. Designed to help players understand team compositions, evaluate draft decisions, and identify the strengths and weaknesses of both teams.

This page is currently available in English. Khmer translation is planned.

What is Jongrai?

Jongrai is a draft board designed to help you manage and analyze a ranked draft from beginning to end. Pick and ban heroes for both teams, assign lanes, and receive a live assessment of the draft as it develops.

Once the draft is completed, Jongrai provides a final assessment explaining each team's strengths and weaknesses. Its purpose is to explain the draft, not predict the match result.

Data Sources & Methodology

Jongrai combines publicly available information, community-maintained datasets, and manually curated content.

  • Hero roster - The shipped data/heroes.csv, based on patch .
  • Hero tiers - November 2026 lane tier lists, mapped to the S-D scale. Each hero receives the tier of its strongest lane.
  • Win, pick and ban rates - Official Mobile Legends rank statistics, covering all ranks over the past 30 days. Updated 6 November 2026.
  • Counters and synergies - Moonton's official in-game hero relations, obtained through MLBB-API (MIT License).
  • Hero attributes - Moonton's in-game ratings for durability, offense, control, and speciality.
  • Power spikes (EARLY / MID / LATE) - The community dataset MLBB-DRAFT-ANALYSIS (ISC License). These classifications reflect one author's judgement and are not official ratings.
  • Item catalog - The shipped data/items.csv, sourced from MLBBHub, with structural item data derived from Moonton and Liquipedia.
  • Core builds per hero - The shipped data/hero-builds.csv, containing five manually curated core builds per hero, sourced from MLBBHub and reviewed against patch . These builds are editorial recommendations, not official builds.

Meta Ban Classification

Jongrai classifies a hero as a meta ban when its ban rate reaches 15% or higher.

All statistics are reference data and do not guarantee in-game performance.

The AI Coach

Jongrai includes an optional AI-powered coach that provides a final draft verdict using an AI model configured by the user. The coach is instructed to evaluate the draft using patch data and the information visible on the draft board.

How It Works

  • The AI is not called while a draft is still in progress.
  • Once a draft is completed, the coach can evaluate the available information.
  • Its response is cached for that draft, preventing unnecessary repeat requests and charges when the interface re-renders.
  • Your API key is stored locally in ai-config.txt, which is excluded from Git through .gitignore.

Important: The AI coach provides an opinion, not an authoritative source of truth. Hero statistics, counters, tiers, and other underlying data should be treated as the primary references.

Running Jongrai

Jongrai requires Java 17 or newer. No build tools, external dependencies, or additional installations are required.

./build.sh  (Windows: .\build.ps1)
java -cp out jongrai.WebServer
